For grown-ups. These words are saved on this iPad only and never leave it.

Players

Each player has their own world and toy box. Their name shows under their picture, and a 4-number code keeps the other one out. Leave the code empty for no code.

Opens either world. Once it's set, this box asks for it too, so only grown-ups can change the codes.

Backup

Saves every drawing, both worlds and these settings into one file (choose "Save to Files"). Each Home Screen icon keeps its own saved things, so before adding the app to the Home Screen again, save a backup here, then put it back in the new one.
